# Qa-link-checker

A Python-based QA automation tool that scans websites for broken links and validates page responses. Built to bring automated testing practices into everyday quality assurance work.

## Features
- Reads a list of URLs from an external file (`urls.txt`)
- Checks each URL's HTTP status code
- Measures response time for each request
- Generates a clean, readable report (`report.txt`)
